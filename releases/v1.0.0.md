# v1.0.0

The initial release contains the 132-byte initialization table for
the SPI display on DFRobot UNIHIKER M10 V1.2. The bytes were verified
on that board with Linux `panel-mipi-dbi`. See the panel README
for the tested behavior and remaining test gaps.

Download `dfrobot-unihiker-m10-display.tar.gz`, extract it, and check
the included `SHA256SUMS`. The archive preserves the comma in
`dfrobot,unihiker-m10-display.bin`, which Linux uses as the firmware
filename. GitHub may replace the comma in the separately uploaded
binary's asset name with a dot.

Install the file in the firmware search path; for early kernel probe,
include it in the initramfs or kernel with `CONFIG_EXTRA_FIRMWARE`.

This release does not claim compatibility with other ILI9341
modules or M10 hardware revisions.
